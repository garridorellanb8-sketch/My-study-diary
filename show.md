description: Abre el proyecto actual en Google Chrome
---

Abre el proyecto actual en Google Chrome para que el usuario pueda visualizarlo y comprobar su funcionamiento.

Instrucciones:

1. Identifica automáticamente la carpeta raíz del proyecto actual.
2. Comprueba cómo se ejecuta el proyecto.
3. Si es necesario, inicia el servidor de desarrollo.
4. Abre la aplicación en Google Chrome.
5. No modifiques ningún archivo del proyecto.
6. No hagas cambios en el código.
7. Si el proyecto ya tiene un servidor ejecutándose, utiliza ese servidor en lugar de iniciar otro.
