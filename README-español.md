# Mi diario de estudio
## Es una aplicación para motivar a los estudiantes de informática a seguir estudiando mediante rachas y objetivos.

# ¿Qué tiene?
### Un botón para cambiar entre modo claro y oscuro.

### Tres marcadores para ver la racha actual, el récord de racha y las rachas del mes.

### Una sección para crear sesiones de estudio con fecha, qué has estudiado y cuánto tiempo has estudiado.

### Un apartado opcional de apuntes para guardar cosas importantes que no quieres olvidar.

### Puedes editar o borrar las sesiones que hayas creado.

### Puedes ponerte objetivos de estudio para intentar cumplirlos como motivación.

### Una heatmap para ver cuánto has estudiado durante las últimas semanas.

# Por qué lo he hecho?
### Este proyecto es mi proyecto final del curso “Desarrollo con IA: el nuevo programador” de Brais Mouredev.

### Y sí, lo he hecho con IA, pero he aprendido un montón de cosas que me parecen muy útiles para desarrollar una aplicación.

### Lo que más me ha gustado aprender es que no se trata simplemente de decirle a la IA que haga algo. Hay que saber cómo decirle lo que tiene que hacer de forma controlada y responsable y, lo más importante, saber lo que está haciendo en todo momento.

# Cómo lo he hecho?
### Durante el curso aprendí y utilicé:

### LLMs y prompting estructurado.

AGENTS.md para definir cómo quiero que trabaje el agente.

MEMORY.md para que el agente pueda saber cómo continuar el proyecto.

Commands y Skills.

MCPs, como Chrome DevTools y Context7.

Spec-Driven Development (SDD) para planificar, revisar e implementar.

Agents y Subagents.

Al final creé un grupo de agentes que funciona así:

Coordinator → Planner → Implementer → Reviewer

El Coordinator da las instrucciones, el Planner prepara el plan, el Implementer lo desarrolla y el Reviewer revisa el resultado.

Una cosa que aprendí durante el curso y que personalmente me parece importante es que no hay que dejar que la IA haga todo sin control. Por ejemplo, aprendimos a usar /init para que el agente cree el AGENTS.md, pero yo personalmente prefiero hacerlo yo mismo porque creo que nosotros tenemos que controlar cómo queremos que trabaje el agente.

 Lo que he aprendido
Este proyecto me ha servido para aprender que desarrollar con IA no significa simplemente dejar que la IA programe por ti.

Para mí significa aprender a utilizarla como una herramienta, entender lo que hace, revisar el resultado y saber cuándo hay que corregirla.

Y eso es precisamente lo que quería aprender con este proyecto.
